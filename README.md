# CollegePath

A free, self-contained college admissions guide built specifically for **H-1B / H-4 visa families** in the US.

## What it does

- **6-step wizard** — collects GPA, SAT/ACT, major interest, budget, and location preference
- **75-college database** — Ivy League, elite privates, top publics, and liberal arts colleges
- **Smart matching** — categorizes each school as Reach / Target / Likely / Financial Safety based on your profile
- **Cost analysis** — full Cost of Attendance with out-of-state vs in-state breakdowns
- **H-4 visa guidance** — per-school info on merit aid eligibility, state DREAM Act status, and FAFSA limitations
- **SAT/ACT strategy** — tailored prep advice based on score gaps
- **Junior year timeline** — month-by-month action plan
- **Compare tool** — side-by-side comparison of up to 4 colleges
- **Dark/light theme** — full system theme support

## How to run

Just open `final.html` in any browser — no server, no build step, no dependencies.

```
open final.html
```

## File structure

| File | Purpose |
